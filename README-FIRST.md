# How to use this pack
1. Create the project repo and copy everything in this folder into its root (keep the folder names).
2. Commit it as the first commit: "docs pack".
3. Open the repo in the first agent (Copilot or Antigravity) and paste the "First prompt" from PROMPTS.md.
4. Commit after every task. Update docs/HANDOFF.md every 30 to 45 minutes.
5. When a limit hits, open the repo in the other agent and paste the same "First prompt".
Files:
- AGENTS.md: rules both agents follow
- .github/copilot-instructions.md and .agent/rules/project.md: pointers to AGENTS.md
- docs/: PROJECT, ARCHITECTURE, DECISIONS, PHASES, HANDOFF
- PROMPTS.md: prompts for you to paste
